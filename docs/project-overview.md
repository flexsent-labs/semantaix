# Semantaix — Project Overview

_Generated by BMAD `document-project` (deep scan), 2026-06-19. Reflects the system **as-built** on `origin/main` @ `475b3d6`._

## Purpose

Semantaix is a **Russian-first, Telegram-native customer-conversation platform** for service
businesses (salons, clinics, studios). A customer messages a Telegram bot (or an operator's
linked user account); the platform answers **only from grounded, operator-curated knowledge**,
and escalates to a human (HITL) whenever it cannot answer safely. Around that core it layers a
sales/booking persona, calendar availability, a services catalog, knowledge moderation, incident
alerting, usage/cost monitoring, backups, and operator self-registration.

The guiding safety invariant: **a wrong answer is worse than an escalation.** The LLM is never
user-visible unless its output clears four independent grounding layers.

**telegram_bot_api** server is included for self-hosted Bot API.

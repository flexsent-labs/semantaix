## Entry points

- **Customer message** → `bot_gateway` webhook (or `user_gateway` Telethon) → api
  `POST /conversations/inbound` → `AnswerPipeline`.
- **Operator commands** → `bot_gateway` slash-command dispatch (gated on operator/admin username).
- **Admin UI** → `web_ui` (cookie session) → api over `internal_service_token`.
- **Each service** boots from its `app/main.py` via `platform_common/app_factory.create_app(...)`.

## Critical directories

| Directory | Why it matters |
|---|---|
| `services/api/app/answerers/` | The safety-critical answer path; order is the routing logic |
| `services/api/app/calendar/` & `sales/` | Largest recent feature surfaces (epics 11–13) |
| `services/api/app/data/` | Russian tunables loaded at runtime — change behavior without code |
| `platform_common/` | Touching `settings.py`/`app_factory.py` affects every service |
| `_bmad-output/project-context.md` | Mandatory AI coding rules — read before editing |

## Composition root

`services/api/app/main.py` is the api composition root (~4,400 lines). It builds the FastAPI app
via `platform_common/app_factory.py`, instantiates every repository against `.data/*.db`, and
assembles the answer pipeline (`main.py:696`):

```
AnswerPipeline([
    SalesPersonaAnswerer,          # epic 12 — owns in-scope sales/booking turns
    CalendarAvailabilityAnswerer,  # epic 11 — availability gate before grounded RAG
    GroundedRagAnswerer,           # epics 03/05/13 — 4-layer grounded answer + catalog merge
    ScopeGuardAnswerer,            # defers/declines out-of-scope
])
```

**Order IS the routing logic** — first `handled=True` wins; otherwise the request escalates to HITL.

## Cross-cutting conventions (enforced)

- **httpx is the outbound transport idiom**; external results are frozen `@dataclass`es.
- **Network I/O is async; SQLite is sync** — repos use blocking `sqlite3`, called from async via
  `await asyncio.to_thread(...)`. No raw SQL outside `*Repository` classes (~37 repositories).
- **Time is injected, never ambient**; all datetimes tz-aware; UTC ISO-8601 at rest.
- **Failure convention is per-layer**: answerers dispatch (skip) and never raise into the pipeline;
  repositories raise typed domain errors; endpoints raise `HTTPException`. Degraded-but-owned →
  escalate to HITL, never silent fall-through.
- **Secrets come from `Settings` (env)**, never stored in repo columns or logs. Per-operator
  calendar refresh tokens are Fernet-encrypted at rest.
- **Structured logging**: `snake_case verb_noun` event literal + `trace_id`, never f-stringed.
- **Tunable runtime config in `hitl_runtime_config`** (DB-first, `.env` fallback); tunable
  Russian phrase lists in `data/*.txt|*.json`, loaded at runtime.

## Russian-first text seam

`RussianNormalizer` (`russian_text/`) wraps razdel + static slang dict (`data/russian_slang.json`)
+ pymorphy3. It is the **single shared seam** across retrieval (`rag.py` `_tokenize`), guardrails
(`data/russian_hedges.txt`, `data/russian_policy_phrases.txt`), profanity
(`data/russian_profanity.txt`), and intent (`scheduling_context.py`). Add slang/phrase entries to
the data files — never as Python literals.

## Provisioned-but-unused

- **Qdrant** (6333): in compose + readiness checks (`qdrant_url`) but **no vector index/query**.
  Retrieval is lemma-overlap. Kept as the forward path for embeddings.
- **PostgreSQL**: `database_url` defaults to a Postgres DSN; `postgres` compose service is behind
  `profiles: [with-postgres]`. No Postgres driver is imported; not on the runtime path.
